# miPall - Earn Rewards & Micro Jobs 🚀

miPall is a modern, mobile-first micro-task and investment platform built with React, Vite, and Tailwind CSS. The platform enables users to complete short tasks, invest in premium plans, earn rewards, and manage digital wallets seamlessly.

## 🌟 Key Features

### 👤 User Features
* **Authentication:** Secure login and registration.
* **Wallet & Finances:** Manage balances, make deposits (via automated gateways like bKash/Nagad), and request withdrawals.
* **Micro Jobs & Earnings:** Complete simple daily tasks (video ads, website visits, math quizzes) for real cash rewards.
* **Investment Plans:** Subscribe to premium daily earning plans to boost limits.
* **Referral System:** Invite friends to earn signup bonuses and lifetime deposit commissions.
* **PWA Ready:** Installable as a progressive web app with seamless full-screen mobile experience.

### 🛡️ Admin Panel Features
* **Dashboard:** Comprehensive insights, total user base, balances, and real-time revenue analytics.
* **User Management:** View, ban/unban, and edit user balances.
* **Task Management:** Create and distribute video, quiz, or website tasks.
* **Deposit & Withdraw Approvals:** Approve or reject manual transaction requests.
* **Site Settings:** Update app branding, logo, dynamic mobile APK URL, and support contacts (WhatsApp/Telegram).

## 🛠️ Technology Stack

* **Frontend:** React 18, TypeScript, Vite
* **Styling:** Tailwind CSS, Lucide React Icons
* **Routing:** React Router v6
* **Charts:** Recharts for dynamic visual analytics
* **State Management:** React Context API

## 📱 Progressive Web App (PWA) Setup

2. Enter the live URL of your deployed application.

## 🚀 Getting Started

### Prerequisites
* Node.js v18+ 
* npm or yarn

### Installation
1. Clone the repository
2. Install dependencies:
   \`\`\`bash
   npm install
   \`\`\`
3. Start the development server:
   \`\`\`bash
   npm run dev
   \`\`\`
4. Build for production:
   \`\`\`bash
   npm run build
   \`\`\`
